# MD Viewer

A minimal, client-side Markdown viewer that runs entirely in the browser. Single HTML file, zero build step.

## Features

- Live split-pane editor with real-time preview
- Drag & drop or open `.md` files
- Syntax highlighting for code blocks
- Auto-generated table of contents
- Light and dark themes
- GitHub-flavored Markdown (tables, task lists, alerts)
- Word count, character count, reading time
- Resizable editor/preview panels
- HTML sanitisation via DOMPurify

## Usage

Open `index.html` in any modern browser — that's it.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open file |
| `Ctrl+Shift+D` | Toggle dark mode |
| `Ctrl+\` | Toggle table of contents |
